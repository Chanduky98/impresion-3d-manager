🔄 RESET Y LIMPIEZA
====================================================================

Para resetear TODO y empezar de nuevo:

$ npx prisma db reset

Esto:
  ✓ Elimina la BD actual
  ✓ Crea una BD nueva
  ✓ Ejecuta todas las migraciones
  ✓ Carga los datos de ejemplo

====================================================================

🚀 PRIMER INICIO
====================================================================

OPCIÓN A - AUTOMÁTICO (RECOMENDADO):
  1. Doble-click en INICIAR.bat
  2. Espera a que se complete todo
  3. Abre el navegador en http://localhost:3000/dashboard

OPCIÓN B - MANUAL:
  1. npm install
  2. npx prisma migrate dev --name init
  3. npx prisma db seed
  4. npm run dev
  5. Abre http://localhost:3000/dashboard
