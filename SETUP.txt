GESTOR DE IMPRESIÓN 3D - GUÍA DE INSTALACIÓN Y EJECUCIÓN
====================================================================

REQUISITOS PREVIOS:
- Node.js 18+ instalado en el sistema
- NPM (incluido con Node.js)

BASE DE DATOS:
- SQLite local (automático)
- No requiere servidor externo
- Se crea automáticamente en: ./prisma/dev.db

INSTALACIÓN RÁPIDA:
====================================================================

1. OPCIÓN A - Usando el archivo de lotes (RECOMENDADO):
   - Ejecuta: INICIAR.bat
   - El sistema hará todo automáticamente:
     * Instalará dependencias
     * Creará la base de datos
     * Cargará datos de ejemplo
     * Iniciará el servidor
     * Abrirá el navegador en http://localhost:3000/dashboard

2. OPCIÓN B - Instalación manual:

   Paso 1: Instalar dependencias
   $ npm install

   Paso 2: Crear la base de datos
   $ npx prisma migrate dev --name init

   Paso 3: Cargar datos de ejemplo
   $ npx prisma db seed

   Paso 4: Iniciar el servidor de desarrollo
   $ npm run dev

   Paso 5: Abrir en navegador
   - URL: http://localhost:3000/dashboard

SOLUCIÓN DE PROBLEMAS:
====================================================================

ERROR: "Module not found" al iniciar
SOLUCIÓN: Ejecutar npm install nuevamente

ERROR: "Port 3000 already in use"
SOLUCIÓN: Cambiar puerto con: npm run dev -- -p 3001

ERROR: Base de datos corrupta
SOLUCIÓN: Eliminar ./prisma/dev.db y ejecutar setup nuevamente

ERROR: Datos no aparecen
SOLUCIÓN: Ejecutar npx prisma db seed nuevamente

VERIFICAR INSTALACIÓN:
====================================================================

1. ¿Node.js instalado?
   $ node --version
   (Debe mostrar v18.0.0 o superior)

2. ¿NPM instalado?
   $ npm --version

3. ¿Servidor corriendo?
   - Abre navegador en http://localhost:3000/dashboard
   - Deberías ver el dashboard
